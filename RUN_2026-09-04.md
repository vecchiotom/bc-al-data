## Fixes made this run

- **verify was fundamentally wrong** — wrapped an extracted member in a bare
  codeunit; sibling/`Rec` references didn't resolve. Replaced with in-app
  compilation (`verify_inapp.py`).
- baseline fast-path key mismatch (`vendor/bcapps` vs symlink-resolved
  `vendor/BCApps`) made every g1/g2/g6 do a full recompile.
- G2 ~35 % false-negatives — candidate for overload N was compiled against
  overload 1; now disambiguated by signature.
- G6 returned 0 — the origin guard required `meta.member`, which object-level G6
  doesn't have.
- `filter` collapsed all 14 mutations of a member to one row — preference rows
  now dedup on `prompt + rejected`.
- `assemble` — `kind_cap` was unused; whole-app heldout key was wrong for G6.
- G7 (`run_g7`) still used the broken snippet compile — now in-app + autofix.
